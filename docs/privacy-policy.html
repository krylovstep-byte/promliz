Политика ООО «МБ-Лизинг» в отношении обработки персональных данных на сайте

Настоящая Политика в отношении обработки персональных данных (далее - «Политика») действует в отношении обработки Оператором ООО «МБ-Лизинг» (ООО «МБЛ»), 150040, Россия, г. Ярославль, ул. Победы, 38/27, офис 512, ОГРН 1107604017586, ИНН 7604191382, КПП 760401001 (далее - «Компания») персональных данных пользователей сайта https://promliz.com/ Компании (далее - «Сайт»).

Цель обработки персональных данных - осуществление деятельности ООО «МБ-Лизинг» с использованием интернет-сайта.

1. Основные понятия

Автоматизированная обработка персональных данных - обработка персональных данных с помощью средств вычислительной техники.

Обработка персональных данных - любое действие (операция) или совокупность действий (операций), совершаемых с использованием средств автоматизации или без использования таких средств с персональными данными, включая сбор, запись, систематизацию, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу, блокирование, удаление, уничтожение персональных данных.

Персональные данные - любая информация, относящаяся к прямо или косвенно определенному или определяемому физическому лицу (субъекту персональных данных).

Субъект персональных данных - физическое лицо, которое прямо или косвенно определено или определяемо с использованием персональных данных.

Уничтожение персональных данных - действия, в результате которых становятся невозможными восстановить содержание персональных данных в информационной системе персональных данных и (или) в результате которых уничтожаются материальные носители персональных данных.

Cookie - текстовые файлы, содержащие небольшие фрагменты данных, которые создаются и сохраняются браузером при посещении сайтов и сервисов. С их помощью Сайт запоминает данные о посещениях Сайта пользователями.

2. Правовые основания обработки персональных данных

Обработка персональных данных пользователей сайта производится на основании согласия пользователей Сайта как субъектов персональных данных. На обработку персональных данных в целях улучшения работы Сайта в интересах пользователей и персонализации пользователь Сайта соглашается, оставаясь на Сайте.

3. Обрабатываемые персональные данные и условия обработки

Компания обрабатывает следующие персональные данные пользователей Сайта:

Цель 1: Обработка заявок, оставленных на Сайте

Цель обработки: Обработка заявок оставленных на Сайте с целью получения услуг, предоставляемых Компанией.

Перечень персональных данных: Фамилия, имя, отчество, номер телефона, адрес электронной почты.

Способ обработки: Способом смешанной обработки с использованием средств автоматизации и без использования таких средств. Метрический интернет-сервис «Яндекс.Метрика».

Способ уничтожения: Электронные данные уничтожаются путем удаления из информационных систем Компании с помощью встроенных средств информационных систем. Данные на бумажных носителях уничтожаются путем шредирования или путем помещения в опечатанные емкости и дальнейшего уничтожения методом, исключающим восстановление.

Цель 2: Улучшение работы Сайта

Цель обработки: Улучшение работы Сайта в интересах пользователей и персонализация.

Перечень персональных данных: Электронные данные (HTTP-заголовки, IP-адрес, файлы cookie, веб-маяки/пиксельные теги, данные об идентификаторе браузера, данные о типе устройства и операционной системе, дата и время осуществления доступа к сайтам и/или сервисам; информация об источнике перехода на сайт; информация об активности во время использования сайта), файлы cookie, установленные в том числе сервисом «Яндекс Метрика».

Способ обработки: Автоматизированная обработка в информационных системах.

Способ уничтожения: Электронные данные уничтожаются путем удаления из информационных систем Компании с помощью встроенных средств информационных систем.

Срок обработки персональных данных

Компания прекращает обработку вышеуказанных персональных данных:

  • по достижению цели их обработки;
  • при утрате необходимости в достижении цели их обработки;
  • по истечении срока действия согласия на обработку персональных данных или отзыве согласия, при отсутствии иных законных оснований для обработки персональных данных.

По истечении указанных сроков Компания может обрабатывать персональные данные, если обработка необходима для соблюдения действующего законодательства Российской Федерации.

Перечень действий с персональными данными

Применительно ко всем вышеуказанным персональным данным Компания может совершать следующие действия: сбор, запись, систематизация, накопление, хранение, уточнение (обновление, изменение), извлечение, использование, передачу, блокирование, удаление, уничтожение персональных данных, в том числе с использованием сервиса «Яндекс.Метрика». С согласия субъекта персональных данных Компания может осуществлять распространение персональных данных.
